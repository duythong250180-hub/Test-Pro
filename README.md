# Test-Pro
Test-Pro là dự án xây dựng phần mềm kiểm tra trắc nghiệm trực tuyến miễn phí, hỗ trợ giáo viên tạo đề thi, tổ chức kiểm tra và quản lý kết quả học sinh. Dự án sử dụng VS Code, GitHub và Firebase, hướng đến giao diện thân thiện, dễ sử dụng, bảo mật dữ liệu và thuận tiện triển khai trên Internet.
